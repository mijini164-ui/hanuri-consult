# 한우리 신규 상담 안내문 만들기

신규 회원 상담 때 학부모님께 드리는 **A4 3장** 안내문을 만드는 페이지예요. (한우리 수업도우미와는 별개 도구예요.)

주소: https://mijini164-ui.github.io/hanuri-consult/

| 장 | 내용 | 선생님이 고치는 곳 |
|---|---|---|
| 1장 | 한우리 소개 · 한 달 4차시 수업 · 학년별 프로그램 | 공통 글 ('글 직접 고치기'로 수정 가능) |
| 2장 | 읽고 퀴즈만 푸는 수업과 한우리 수업 비교 · 수업 흐름 · AI 시대 생각하는 힘 | 공통 글 |
| 3장 | 교사관 · 우리 교실만의 특별한 점 3가지 · 수업 시간표 · 첫 수업까지 · 연락처 | 왼쪽 입력칸 |

- 저장: **PDF로 저장**(인쇄용) · **그림으로 저장**(3장) · **인쇄**
- 적은 내용은 그 기기 브라우저에만 저장돼요(`localStorage` `consult_v1`). 서버로 가지 않아요.
- 다른 지부는 왼쪽 **지부 이름·지부 전화**만 바꾸면 돼요.
- 파일: `index.html`, `css/consult.css`, `js/consult.js`. 기본 문구는 `index.html`의 `data-k` 글과 `js/consult.js`의 `PHIL`(교사관 예시)·`POINTS`(특별한 점 예시)·`DEF.rule`(수업 기준)에 있어요.
- `main`에 올리면 GitHub Actions가 자동으로 사이트에 반영해요.
