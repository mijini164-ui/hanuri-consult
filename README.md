# 한우리 신규 상담 안내문 만들기

신규 회원 상담 때 학부모님께 드리는 **A4 한 장** 안내문을 만드는 페이지예요. (한우리 수업도우미와는 별개 도구예요.)

주소: https://mijini164-ui.github.io/hanuri-consult/

| 순서 | 내용 | 선생님이 고치는 곳 |
|---|---|---|
| 맨 위 | 큰 제목 | 예시 고르기 또는 직접 쓰기 (`[ ]` 안은 주황색) |
| 01 | 우리 수업을 소개해요: 한우리 독서지도사 이름 · 교사관 · 6세~고등 / 주 1~2회 / 독서지도사 | 왼쪽 입력칸 |
| 02 | 한 달 4차시 수업 + 몰입독서·월 2회 수업 시 조정 안내 | 공통 글 |
| 03 | 한우리 수업의 강점 6가지 | 공통 글 |
| 04 | 수업 시간 안내: 단계 고르기 3칸 + 요일·시간, 고른 단계만 짧게 소개 | 왼쪽 입력칸 |
| 끝 | 마지막 한마디 · 교실 · 선생님 이름 · 전화번호 | 왼쪽 입력칸 |

- 저장: **PDF로 저장**(인쇄용) · **그림으로 저장** · **인쇄**
- 적은 내용은 그 기기 브라우저에만 저장돼요(`localStorage` `consult_v3`). 서버로 가지 않아요.
- 다른 지부는 왼쪽 **지부 이름·지부 전화**만 바꾸면 돼요.
- 파일: `index.html`, `css/consult.css`, `js/consult.js`. 기본 문구는 `index.html`의 `data-k` 글과 `js/consult.js`의 `PHIL`(교사관 예시)·`TITLES`(큰 제목 예시)·`COURSES`(단계와 소개)·`DEF.rule`(수업 기준)에 있어요.
- `main`에 올리면 GitHub Actions가 자동으로 사이트에 반영해요.
